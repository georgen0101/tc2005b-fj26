# Guía de Contribución

¡Gracias por tu interés en contribuir a este proyecto de aprendizaje!

## Cómo Contribuir

### 1. Fork y Clona

```bash
git clone https://github.com/tu-usuario/tc2005b-fj26.git
cd tc2005b-fj26
```

### 2. Crea una Rama

```bash
git checkout -b feature/tu-feature
# o
git checkout -b fix/tu-bug-fix
```

### 3. Realiza tus Cambios

- Mantén tu código limpio y legible
- Agrega comentarios donde sea necesario
- Asegurate de seguir la estructura del proyecto

### 4. Commit de tus Cambios

```bash
git add .
git commit -m "descriptive: mensaje claro del cambio"
```

### 5. Push a tu Fork

```bash
git push origin tu-rama
```

### 6. Abre un Pull Request

- Usa el template de PR proporcionado
- Completa todos los campos del checklist
- Describe claramente qué cambios realizaste y por qué

## Estándares del Proyecto

- 📝 **Código limpio y legible**: Mantén el código fácil de entender
- 📚 **Documentación**: Documenta cambios significativos
- ✅ **Testing**: Verifica tus cambios localmente antes de hacer PR
- 🎯 **Commit messages**: Usa mensajes claros y descriptivos

## Formato de Commits

```
tipo: descripción breve

descripción detallada (opcional)
```

**Tipos comunes:**

- `feat:` - Nueva funcionalidad
- `fix:` - Corrección de bugs
- `docs:` - Cambios en documentación
- `refactor:` - Cambios de código sin new features
- `test:` - Agregar o modificar tests
- `chore:` - Cambios en configuración

## Preguntas o Dudas

Si tienes dudas sobre cómo contribuir, abre un issue y estaremos encantados de ayudarte.
